## One Public Model, Several Client Protocols

Codex Pooler is a self-hosted pooled gateway for trusted coding agents, SDKs, and automation. Clients authenticate with stable Pool API keys and see one virtual model: `gemma3`.

The server owns the real target, reasoning policy, account selection, retries, continuity, quota handling, and accounting. Changing a client model name cannot change that decision, and private provider/account/assignment details do not cross the client boundary.

## Client URLs

| Client family | Base URL | Guide |
| --- | --- | --- |
| Ollama | `http://localhost:4000` | [Ollama clients](/clients/ollama/) |
| OpenAI-compatible SDKs | `http://localhost:4000/v1` | [OpenAI-compatible SDKs](/clients/openai-compatible/) |
| Claude Code / Anthropic Messages | `http://localhost:4000` | [Claude Code](/clients/claude-code/) |
| Codex CLI / Desktop | `http://localhost:4000/backend-api/codex` | [Codex CLI and Desktop](/clients/codex-cli/) |

Use `gemma3` in every model field. For a deployed instance, replace `http://localhost:4000` with your origin, such as `https://codex-pooler.example.com`.

All four runtime families require a Pool API key. Never place an upstream account credential in a client. The optional `/mcp` endpoint is a separate read-only operator service and requires a separate operator MCP token.

## What It Provides

- **Immutable public identity:** discovery, responses, streams, and protocol-native errors expose only `gemma3`.
- **Central Pool policy:** health, quota evidence, assignment eligibility, key policy, continuity, and routing determine where work runs.
- **Pre-visible retries:** retryable failures can move before output; turns are never replayed after visible output.
- **Scoped cache locality:** client cache/session hints are namespaced to the Pool and API key instead of becoming cross-client identifiers.
- **Protocol-native adapters:** Ollama JSON/NDJSON, OpenAI JSON/SSE/websocket, Anthropic Messages JSON/SSE, and Codex backend transports keep their documented framing.
- **Truthful operator evidence:** authorized operators retain sanitized routing and accounting metadata without exposing it to clients.
- **Content privacy:** request logs do not retain raw prompts, completions, tool payloads, file/media bodies, websocket frames, Pool keys, or upstream credentials.

## Compatibility Boundary

Codex Pooler is not a local Ollama daemon and does not download model weights. It is not a full OpenAI or Anthropic API clone, and it is not a wildcard Codex app-server proxy.

Codex CLI and Claude Code continue to supply their own local agent behavior: repository discovery, tool execution, sandboxing, edits, tests, conversation storage, interruption, and resume. The gateway supplies the model transport and pooling boundary. Adapters preserve supported semantics but do not promise token-for-token equivalence between different wire protocols or with a direct service connection.

Identity projection applies to protocol fields, safe headers, and errors. Arbitrary generated prose is not blindly rewritten.

## Frequently Asked Questions

### Which model does a client configure?

Always `gemma3`. It is the only public identity. Other or missing model selectors on supported inference routes are normalized before the server validates and routes its fixed decision.

### What happens when the fixed target is unavailable?

Catalogs become empty and inference fails closed with a protocol-safe unavailable error. Codex Pooler does not reveal or select a fallback model.

### Does it cache responses?

No. It can improve provider-side prompt-cache locality by converting supported cache/session inputs into Pool-and-key-scoped values. That is a routing hint, not stored-response replay or a guaranteed cache hit.

### Can a client discover the provider or account?

No. Client model fields, discovery, response envelopes, error bodies, streams, and response headers are projected to the virtual identity and stripped of provider/account/assignment metadata. Authorized operator diagnostics remain truthful and metadata-only.
