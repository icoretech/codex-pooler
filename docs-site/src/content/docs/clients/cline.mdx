---
title: Cline
description: Configure Cline for Codex Pooler's bounded OpenAI-compatible gemma3 façade.
---

Cline's `openai` provider shorthand uses the OpenAI-compatible route. Save one custom model:

```bash
cline auth \
  --provider openai \
  --apikey "$CODEX_POOLER_API_KEY" \
  --baseurl https://codex-pooler.example.com/v1 \
  --modelid gemma3
```

For local setup, use `http://localhost:4000/v1`.

```bash
cline --provider openai --model gemma3 --json --auto-approve false \
  'Inspect the repository and report the test command.'
```

Do not add client-side model fallbacks. `GET /v1/models` is authoritative for the virtual model's exposed context metadata. Cline model traffic uses a Pool API key; optional `/mcp` operator metadata requires a separate operator MCP token.
