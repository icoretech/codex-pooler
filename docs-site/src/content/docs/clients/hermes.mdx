---
title: Hermes Agent
description: Configure Hermes Agent for Codex Pooler's bounded OpenAI Responses gemma3 façade.
---

Use Hermes' `openai-api` provider and one public model. Keep the Pool key in `~/.hermes/.env` or another private environment source:

```bash
OPENAI_API_KEY=<pool-api-key>
OPENAI_BASE_URL=https://codex-pooler.example.com/v1
```

```yaml
# ~/.hermes/config.yaml
model:
  default: gemma3
  provider: openai-api
  base_url: https://codex-pooler.example.com/v1
  api_mode: codex_responses
  supports_vision: true

agent:
  image_input_mode: native

image_gen:
  provider: openai
  model: gemma3
```

For local setup, use `http://localhost:4000/v1`. The gateway owns both reasoning and dedicated media helper selection; Hermes must not configure or discover a second model.

```bash
hermes -z 'Inspect the repository and report the test command.' --ignore-rules
```

`/v1` is bounded compatibility, not full OpenAI API parity. Optional `/mcp` operator metadata uses a separate operator MCP token.
