---
title: Continue
description: Configure Continue for Codex Pooler's bounded OpenAI-compatible gemma3 façade.
---

Add one OpenAI provider model to `~/.continue/config.yaml`:

```yaml
name: Codex Pooler
version: 1.0.0
schema: v1

models:
  - name: gemma3 via Codex Pooler
    provider: openai
    model: gemma3
    apiBase: https://codex-pooler.example.com/v1
    apiKey: "${{ secrets.CODEX_POOLER_API_KEY }}"
    roles: [chat, edit, apply, summarize]
    capabilities: [tool_use, image_input]
```

For local setup, use `http://localhost:4000/v1`. If Continue requires a manual `contextLength`, copy the authenticated `GET /v1/models` value rather than inventing another model entry.

The Pool API key authenticates model work. Optional `/mcp` operator metadata is separate and requires an operator MCP token.
