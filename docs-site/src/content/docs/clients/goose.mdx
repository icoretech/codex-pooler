---
title: Goose
description: Configure Goose for Codex Pooler's bounded OpenAI chat-completions gemma3 façade.
---

Configure Goose's OpenAI chat path in `~/.config/goose/config.yaml`:

```yaml
GOOSE_PROVIDER: openai
GOOSE_MODEL: gemma3
OPENAI_HOST: https://codex-pooler.example.com
OPENAI_BASE_PATH: v1/chat/completions
```

Keep the Pool key outside YAML:

```bash
export OPENAI_API_KEY="$CODEX_POOLER_API_KEY"
goose run --no-session --provider openai --model gemma3 \
  --text 'Inspect the repository and report the test command.'
```

For local setup, use `OPENAI_HOST: http://localhost:4000`. Configure no alternate model or fallback. Optional `/mcp` metadata uses a separate operator MCP token.
