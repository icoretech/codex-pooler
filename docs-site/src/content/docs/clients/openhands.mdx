---
title: OpenHands
description: Configure OpenHands CLI for Codex Pooler's bounded OpenAI-compatible gemma3 façade.
---

Use environment overrides so the Pool key and route do not need to be stored in OpenHands state:

```bash
export LLM_API_KEY=<pool-api-key>
export LLM_BASE_URL=https://codex-pooler.example.com/v1
export LLM_MODEL=openai/gemma3

uvx --python 3.12 --from openhands openhands \
  --headless \
  --override-with-envs \
  -t 'Inspect the repository and report the test command.'
```

For local setup, use `LLM_BASE_URL=http://localhost:4000/v1`. The `openai/` prefix selects OpenHands' provider path; `gemma3` is the only model to configure. Do not add client-side fallbacks.

The operator `/mcp` endpoint is unrelated to OpenHands model traffic and does not accept the Pool API key.
