---
title: Aider
description: Configure Aider for Codex Pooler's bounded OpenAI-compatible gemma3 façade.
---

Aider uses the `/v1` base URL and its `openai/` model prefix. Configure only the public virtual model:

```yaml
# ~/.aider.conf.yml or <repo>/.aider.conf.yml
model: openai/gemma3
openai-api-base: https://codex-pooler.example.com/v1
```

For local setup, use `http://localhost:4000/v1`. Keep the Pool API key outside YAML:

```bash
export OPENAI_API_KEY="$CODEX_POOLER_API_KEY"
aider --message 'Inspect the repository and report the test command.'
```

Do not configure fallback model IDs: the gateway advertises only `gemma3` and owns the target and fixed reasoning policy. If Aider needs manual model metadata, create one `openai/gemma3` entry and take its context length from authenticated `GET /v1/models`.

This is bounded OpenAI compatibility. A Pool API key authenticates model work; an operator MCP token is unrelated.
