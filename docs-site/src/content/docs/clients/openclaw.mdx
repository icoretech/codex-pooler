---
title: OpenClaw
description: Configure OpenClaw for Codex Pooler's bounded OpenAI Responses gemma3 façade.
---

Keep OpenClaw on its OpenAI Responses provider path, but define only `gemma3`:

```json5
{
  agents: {
    defaults: {
      model: { primary: "openai/gemma3" },
      compaction: { reserveTokens: 20000 },
    },
  },
  models: {
    mode: "merge",
    providers: {
      openai: {
        baseUrl: "https://codex-pooler.example.com/v1",
        apiKey: "${CODEX_POOLER_API_KEY}",
        api: "openai-responses",
        agentRuntime: { id: "openclaw" },
        timeoutSeconds: 300,
        models: [
          {
            id: "gemma3",
            name: "gemma3",
            reasoning: true,
            input: ["text", "image"],
            contextWindow: 258400,
            contextTokens: 258400,
            maxTokens: 128000,
          },
        ],
      },
    },
  },
}
```

For local setup, use `http://localhost:4000/v1`. Do not configure background or fallback model IDs; point every local role at `openai/gemma3`. Authenticated `/v1/models.context_length` is authoritative for exposed context metadata.

The optional `/mcp` endpoint is operator metadata and requires an operator MCP token, not the Pool key in the model provider.
