---
title: Trae
description: Configure Trae or Trae CN for Codex Pooler's bounded OpenAI chat-completions gemma3 façade.
---

In **Settings → Models**, add one custom model:

| Field | Value |
| --- | --- |
| API format | OpenAI Chat Completions |
| Custom Request URL | `https://codex-pooler.example.com/v1` |
| Full URL | Off |
| Model ID | `gemma3` |
| Display Name | `gemma3` |
| API key | Pool API key |

For local setup, use `http://localhost:4000/v1`. With **Full URL** off, Trae appends `/chat/completions`. If Full URL is on, use `https://codex-pooler.example.com/v1/chat/completions`.

Trae CN uses the same values under **设置 → 模型 → 自定义配置**. Turn Auto Mode off in the model picker and select the one custom `gemma3` entry.

```bash
curl -sS https://codex-pooler.example.com/v1/chat/completions \
  -H 'Authorization: Bearer <pool-api-key>' \
  -H 'Content-Type: application/json' \
  -d '{"model":"gemma3","messages":[{"role":"user","content":"Reply with: connected"}],"stream":false}'
```

Do not point Trae at `/backend-api/codex` or `/mcp`, and do not configure alternate models.
