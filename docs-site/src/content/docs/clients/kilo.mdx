---
title: Kilo
description: Configure Kilo Code for Codex Pooler's bounded OpenAI chat-completions gemma3 façade.
---

Kilo appends `/chat/completions`, so configure the `/v1` base URL and exactly one model in `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "codex-pooler/gemma3",
  "enabled_providers": ["codex-pooler"],
  "provider": {
    "codex-pooler": {
      "options": {
        "apiKey": "{env:CODEX_POOLER_API_KEY}",
        "baseURL": "https://codex-pooler.example.com/v1"
      },
      "models": {
        "gemma3": {
          "name": "gemma3",
          "tool_call": true,
          "reasoning": true,
          "attachment": true,
          "modalities": {"input": ["text", "image"], "output": ["text"]},
          "limit": {"context": 258400, "input": 258400, "output": 64000}
        }
      }
    }
  }
}
```

For local setup, use `http://localhost:4000/v1`. Treat authenticated `/v1/models.context_length` as authoritative when it differs from the static client metadata.

```bash
export CODEX_POOLER_API_KEY=<pool-api-key>
kilo run --model codex-pooler/gemma3 --pure --format json \
  'Inspect the repository and report the test command.'
```

Do not configure fallback models. Optional operator MCP metadata requires a separate operator MCP token.
